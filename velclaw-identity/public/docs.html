Tài liệu API

Tham chiếu đầy đủ cho lớp identity của Velclaw. Mọi endpoint đều có bản máy đọc được trong OpenAPI 3.1.

Xác thực

2 endpoints

GET /auth/login

Bắt đầu đăng nhập. Chuyển hướng tới provider đang cấu hình và đặt cookie state + PKCE (TTL 10 phút).

Velclaw OAuth nếu có VELCLAW_OAUTH_CLIENT_ID, ngược lại dùng Val Town (không cần cấu hình).

GET /auth/callback

Provider gọi lại. Đối chiếu state, đổi code lấy token, verify id_token với JWKS, tạo session và đặt cookie velclaw_session.

codeBắt buộc
stateBắt buộc
errorTuỳ chọn — provider trả lỗi

GET /api/me

Identity của session đang hoạt động. Trả 401 nếu chưa đăng nhập. 

# Response 200
{
  "user": {
    "id": "vt:12345",
    "email": "you@example.com",
    "name": "your-handle",
    "issuer": "valtown"
  }
}

POST /auth/logout

Thu hồi session trong database (không chỉ xoá cookie) và xoá cookie. 

# Response 200
{ "ok": true }

Token

3 endpoints

POST /api/verify

Verify một JWT: chữ ký với JWKS, thuật toán trong allowlist, exp/iss/aud hợp lệ. Nhận token qua header Authorization hoặc body. 

# Request
curl -X POST $BASE/api/verify \
  -H "content-type: application/json" \
  -d '{"token":"eyJhbGciOi..."}'

# Response 200
{
  "valid": true,
  "identity": { "sub": "user_123", "email": "…", "expiresAt": 1793029971000 }
}

Token không hợp lệ trả 401 kèm {"valid": false, "error": "…"}.

POST /api/token

Cấp JWT HS256 ngắn hạn cho user đang đăng nhập.

Cần VELCLAW_IDENTITY_SECRET; trả 500 nếu chưa cấu hình.

GET /.well-known/jwks.json

Bản sao JWKS của upstream (Neon Auth), cache 10 phút. Pin một URL duy nhất thay vì gọi thẳng upstream.

Meta

3 endpoints

GET /api/health

Kiểm tra JWKS có truy cập được và provider đang hoạt động. Trả 503 khi JWKS hỏng.

GET /api/openapi.json

Toàn bộ tài liệu này dạng OpenAPI 3.1. Import được vào Postman, Insomnia, Swagger UI hoặc bất kỳ agent planner nào.

GET /api/skills.json

Danh mục skills dạng JSON. Lọc bằng ?category= hoặc ?q=.

Danh mục Skills

/api/skills.json

Các gói hướng dẫn tái sử dụng cho AI agent, nhóm theo mục đích. Cài bằng npx skills add <owner/repo>.
